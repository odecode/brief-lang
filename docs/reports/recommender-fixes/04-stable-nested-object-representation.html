Intended behavior and failure

Reading the code

&self is a read-only borrow of the planner. return false exits immediately. is_some_and applies a predicate only when an Option contains a value. The removed depth guard was intended to cap recursive enum expansion, but it also boxed finite object images merely because they were encountered deeper in a nested enum.

Why the correction works and how it was checked

The parent could reserve a one-word object handle while the child constructor wrote the full inline object. Removing the enum-depth guard for finite objects preserves the size threshold while making their representation stable. A nested-enum capacity regression and the real rating-save flow verified the correction.
