Enum context for struct fields

Intended behavior and failure

Each object field must be compiled using its declared type. Previously field expression emission inherited the surrounding expected enum, which could belong to an unrelated function return.

Reading the code

&mut self permits changing compiler state. std::mem::replace installs a new value and returns the previous one. clone duplicates type metadata. filter keeps only fields that are enums. The helper saves the surrounding expected_enum_type, installs the field’s enum type, emits the field expression, restores the original context, then records the declared type for ownership handling.

Why the correction works and how it was checked

OwnedOperationJob previously inherited Result context rather than OperationJob; a tag then selected the wrong payload capacity. Scoped context prevents this cross-expression leakage. A regression checks correct field context and restoration; both app targets built afterward.
